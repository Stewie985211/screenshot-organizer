# v0.2.2 审查与修复记录

日期：2026-10-14。Windows x64 本地桌面工具。修复涉及扫描、识别、文件移动/撤销/恢复、持久化、运行环境和正式界面。

## 修复清单

| 编号 | 级别 | 原行为与影响 | 修复 |
|---|---|---|---|
| A01 | P1 | 未完成操作的图片仍可建立或执行另一份预览，产生互相矛盾的操作日志 | 主进程及移动引擎拦截新整理/撤销；识别也先要求恢复；扫描跳过未完成操作涉及的路径，界面禁用相关操作 |
| A02 | P1 | 仅校验哈希与 owned 标记；外部替换的同内容目标仍会被继续操作或删除 | 新记录持久化磁盘与文件身份，继续、回滚和撤销核对身份及暂存硬链接，外部替换保留两侧 |
| A03 | P1 | 回滚未检查来源目录链；来源换为 junction 后仍可能删除整理目标 | 回滚检查两侧目录链与普通文件类型；拒绝链接；暂存文件也检查类型 |
| A04 | P1 | 来源被新文件占用后扫描留下另一个图片 ID；新文件移走后撤销已恢复文件，却被数据库路径唯一约束判为失败 | 文件验证完成后事务合并失效的同路径记录，并原子写入最终图片与操作状态 |
| A05 | P2 | 恢复失败仍显示此前中断原因，重启后最新冲突不保留 | 恢复失败保存具体错误、失败阶段和更新时间 |
| A06 | P1 | 预览与设置保存只有入口 busy 检查；异步校验期间可交错更新 | 预览、设置和任务共用完整执行期互斥锁 |
| A07 | P1 | 来源先 realpath 再检查，直接选择链接会被规范化掩盖 | 先检查原路径目录链，再 realpath；来源按 Windows 大小写规则去重 |
| A08 | P1 | 整理输出可选程序根目录或其上级，再用 data 等分类名写入运行目录 | 输出既不能处于运行目录内，也不能包含运行目录 |
| A09 | P2 | JPEG 文件头有效但像素已截断，扫描仍视为可人工整理 | 扫描实际解码小图验证；读取失败清空有效尺寸、禁止整理 |
| A10 | P2 | JPEG 的 EXIF 旋转未用于尺寸和长图裁剪判断，显示与识别方向不一致 | 统一使用自动旋转后的尺寸、概览和局部；更新模型缓存版本 |
| A11 | P2 | 显式重新识别失败仍保留旧人工确认，重扫后可能重新生效 | 强制识别当前项时先清除旧建议与确认，并持久化待识别状态 |
| A12 | P2 | 停用分类后重扫继续显示旧分类结果为已识别 | 旧分类失效后转为待确认，提供启用分类，清除旧确认 |
| A13 | P2 | 每次重试各分配完整超时，单张可消耗约两倍设置时间 | 预处理及重试共用同一截止时间，检查中止信号 |
| A14 | P2 | 原图变更后 image ID 不变，React 保留同一 src，缩略图仍显示旧内容 | 缩略图和放大图 URL 包含内容哈希 |
| A15 | P2 | 识别错误被显示为读取错误，尺寸有效也没有直接重试入口 | 区分两类失败，增加单张重新识别；批量识别也可重试识别失败项 |
| A16 | P2 | 本地服务重复启动可并发；已停止请求仍进入启动 | 启动复用同一 Promise，识别与模型准备传递中止信号 |
| A17 | P2 | 识别输入生成后原图改变，结果仍被缓存到旧哈希 | 写缓存前再次检查原图，并检查任务中止状态 |
| A18 | P1 | 服务父进程已经退出时 stop 直接返回，推理子进程可能占用内存/显存 | 正常停止后检查自有后代；仅清理父 PID、启动时间和运行目录均匹配的进程，不停止复用服务；PowerShell 输出显式 UTF-8 |
| A19 | P2 | 停止整理后历史只有已处理项数量，仍显示全部已整理；零项也显示已整理 | 批次保存计划总量，界面显示部分完成/未执行及未执行数量；旧批次兼容原记录 |

## 复现

在 D 盘项目目录运行：

```powershell
pnpm typecheck
pnpm test
pnpm build
# 以下需要先准备本地模型和打包应用，串行运行
pnpm test:integration -- --packaged
pnpm test:audit
```

测试通过合成样本或项目内副本执行，不使用个人原图进行移动。涉及错误服务响应和超时的核心测试使用模拟响应；桌面识别成功使用真实本地模型。测试生成的数据库、日志、截图、运行环境和模型缓存保存在项目 output/data 中，默认不提交。

## 兼容与边界

新操作记录持久化文件身份；历史操作没有该字段时继续兼容原来的哈希校验，无法补出创建时的身份。批次计划总量为可选字段，旧历史保持可读。仅清理自己启动的本地模型服务，复用服务不会被停止。移动/撤销不覆盖已有文件，目的地需支持硬链接。真实个人截图准确率、其他硬件和不同文件系统仍需单独验证。
