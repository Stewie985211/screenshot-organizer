# 视频识别与一键整理

v0.4.0，2026-10-17。

## 直接整理

扫描完成后，点底部“一键整理”。确认框会显示本次数量、整理目录和处理规则；点击“开始一键整理”后，程序自动识别未识别项，再分类、重命名和移动，无需到侧栏逐项确认。

有勾选时只处理所选素材；没有勾选时处理当前类型、分类、状态和搜索筛选中的未整理素材。已有手工标题与分类优先保留。可用的待确认建议也会采用，包括视频；模型分类可能有误，逐项核对方式继续可用。

损坏文件、读取或识别失败、没有有效标题的占位建议及已停用分类会跳过，并在结果里列出原因。全无效时不创建空整理批次。停止识别后不会自动进入移动阶段；移动期间停止会完成当前文件。成功项可在“整理记录”撤销。

## 本地视频

支持 MP4、MOV、MKV、WebM、AVI、M4V。使用 `ffmpeg` / `ffprobe` 读取视频，在内存中抽取 3～6 帧，每帧最长边 512 像素，复用图片使用的 `qwen3-vl:4b-instruct` 模型。抽样数量受本地 8192 上下文限制，视频默认标记待确认。

点击视频预览可以查看带时间点的抽样画面。没有音频转写，不分析对白，也不保证捕捉快速事件或理解视频的全部过程。纯色画面和无有效输出保持待确认，占位标题不会被一键模式当作有效建议。

本地模型准备完成后无需云端、API Key 或按次付费。抽样画面在内存处理，不保存完整抽帧或音频副本；预览缓存限制 24 项。数据库、日志以及整理目标文件仍会占用磁盘空间。

## 准备 FFmpeg

图片功能不需要视频工具。视频功能需要另外安装 FFmpeg：确认 `ffmpeg` 与 `ffprobe` 能从 PATH 找到并重新打开软件，或将二者放到软件根目录 `tools/ffmpeg`。项目源码及便携包不重复附带 FFmpeg、Ollama 或模型权重。

解码器缺失或视频损坏时会说明具体错误，保留文件。FFmpeg 的许可证以安装版本为准。

## 其他修复

- 扫描后 pending、review 和可重试项可选择或全选；全选只作用于当前筛选，识别和编辑后保留勾选。
- 原手动入口按状态显示“识别所选”“核对所选”“整理预览”；手动流程仍要求待确认项核对。
- 图片先读取 Buffer 再交给 Sharp，避免 Windows 上 WebP 预览缓存锁定原文件而无法移动。
- 沿用原有不覆盖命名、内容和文件身份校验、持久化移动日志、撤销及中断恢复。
